## 目的

`Assets/Art/Concept/forest-biome-sample-map.png` の構図を基準に、森・火山・雪の3バイオームを同じゲーム内の差し替え素材として扱うための Tilemap 用タイルセット案と、配置オブジェクト用アトラス案をまとめる。

このノートは完成素材の仕様ではなく、Unity Tilemap で再構成するための実装検証用アート分解メモとする。

## 生成済み仮アトラス

- 保存先: `Assets/Art/Generated/BiomeAtlas/biome-tile-object-atlas.png`
- 生成方法: `$imagegen` built-in image generation
- 画像サイズ: 1254x1254
- 扱い: 見た目確認と切り出し元に使う仮アトラス。完全な32x32自動グリッドスライス用には端数があるため、Unity導入時は必要部分を切り出して正規グリッド化する。

構成:
- 上段: 森バイオーム。草地、土道、石畳、水辺、崖、森壁、木、切り株、倒木など。
- 中段: 火山バイオーム。火山灰、焦げ道、玄武岩道、溶岩、火山崖、焦げ木、黒岩、赤結晶など。
- 下段: 雪バイオーム。雪原、圧雪道、雪付き石畳、凍結池、氷崖、雪針葉樹、雪岩、氷結晶など。

次の実装作業では、この仮アトラスから `32x32 terrain tiles` と `transparent object sprites` を分けて、Unity Sprite Editor で扱いやすい正式な検証用アトラスへ再整形する。

## 共通レイアウト

森サンプルマップの構造を3バイオーム共通の骨格として扱う。

- 中央: 縦方向に伸びる石畳系の主通路。
- 左側: 草地/灰地/雪地の広場と、自然に曲がるサブ通路。
- 右側: 水辺/溶岩/凍結池の大きなランドマーク。
- 上部と下部: 通行不能な森壁/焦げ木壁/雪針葉樹壁で外周を作る。
- 中央右: 崖と段差で高低差を見せ、通路を自然に絞る。
- 広場: 左中央、中央下、右下に小さな戦闘スペースを置く。
- 障害物: 大木、岩、倒木、切り株、低木相当を通路の縁取りとして置く。

## タイルサイズと構成

- 基準タイルサイズ: 32x32。
- 1バイオームごとに最低 8列 x 8行程度のタイルセットを想定する。
- 地形境界は RuleTile または手動配置を想定し、8方向境界を優先して用意する。
- 完成前の検証では、森・火山・雪で同じタイルID構造を使い、Sprite差し替えで見た目を変える。

## 森タイルセット案

- 草地は単色禁止。`Ground_Base` に短い草線、`Ground_DetailA/B` に花・小石・明暗の粒を入れる。
- 石畳は中央通路の主役なので、丸石の形が1枚ごとに違う差分を最低3枚用意する。
- 水辺は明るい青緑を基調に、岸の土色と草の縁取りを必ず持たせる。
- 森壁は個別木だけでなく、連続した葉冠と幹の帯をタイルとして持つ。

## 火山タイルセット案

- 森タイルと同じID構造で差し替える。
- 歩行可能な灰地は暗くしすぎず、通路との差を赤熱亀裂と岩片で出す。
- 溶岩は危険地形として強く読ませるが、全面を赤一色にせず、暗赤、橙、黄の流れを入れる。
- 黒石道は中央通路のシルエットを森版と揃え、ひび割れと赤い隙間で火山らしさを出す。
- 森壁相当は焦げ木、黒岩、溶岩結晶の混合壁にする。

## 雪タイルセット案

- 森タイルと同じID構造で差し替える。
- 雪原は白一色禁止。青影、踏み跡、細かい雪粒、薄い氷片で密度を出す。
- 凍結池は水面と同じ外形を維持し、薄青、白ハイライト、亀裂で読み分ける。
- 雪付き石畳は中央通路の形を保ち、石の輪郭が雪に埋もれすぎないようにする。
- 森壁相当は雪をかぶった針葉樹壁にし、木の黒緑と雪の白で通行不能を明確にする。

## オブジェクトアトラス共通方針

- 透明PNGのオブジェクトアトラスを想定する。
- 基準セルは 32x32、64x64、96x96 を併用する。
- 小物は 32x32、通路を塞ぐ中型物は 64x64、大木や壁パーツは 96x96 以上。
- 各オブジェクトは足元影を持たせ、通行不能か装飾かを見た目で分ける。
- Collider は見た目全体ではなく、足元または接地部分に合わせる。

## サンプルマップ再構成手順

1. 森サンプル画像を 32x32 グリッドに重ね、中央主通路、左サブ通路、右水辺、崖、森壁、広場をマスク化する。
2. マスクから `Ground`、`Path`、`Stone`、`Liquid`、`Cliff`、`Wall` のレイヤーを分ける。
3. 同じマスクを火山・雪にも使い、タイルIDだけを各バイオームのSpriteへ差し替える。
4. オブジェクトは Tilemap ではなく Prefab または SpriteRenderer 配置に分け、Collider と Interaction を付けられるようにする。
5. 小物装飾は歩行可能レイヤーに置き、通行不能オブジェクトは Obstacle レイヤーに置く。

## 品質チェック

- 画面のどこを切り取っても、地面ディテール、境界、障害物、小物が存在する。
- 歩行可能なルートは明るさ、道形状、障害物の配置で自然に読める。
- 通行不能な木、水/溶岩/氷、崖、岩は足元や境界が明確。
- 火山と雪は森と同じ構造に見えるが、色と素材で別バイオームだと分かる。
- 記号的な丸・四角ではなく、ピクセルアートの陰影と粒度を持つ。
