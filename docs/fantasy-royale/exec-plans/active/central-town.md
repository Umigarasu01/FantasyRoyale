# 中心街

## 目的

森マップの中心にある村を、東西の大通りに店と家が並ぶ中心街に作り替える。街の建物と小物は、騎士と同じ描き方で描く。

完了条件は次のとおり。

- 中心街が地図に組み込まれ、森の確認用Sceneで歩いて回れる。
- 大通りに屋台とガラクタの露店があり、今のお店（回復薬と弓）をそこで開ける。
- 街の建物と小物が[設置物のデザイン規約](../../product-specs/art/prop-design.md)の描き方で揃い、騎士との大きさの比に理由がある。
- 建物の判定が見た目の接地部に合い、大通りと交差点を塞がない。

## 背景と根拠

2026-11-09に、所有者はお店を作り直すと決め、屋台とガラクタの露店を街に置き、行商人の荷馬車は試合ごとにランダムな場所へ出すことにした。続けて、まず中心街が欲しいとし、噴水広場、大通り、城壁の3案から大通りを選んだ。イメージ図は`Tools/MapAuthoring/Inputs/central-town-concept.png`にある。決定は[Prototype方針](../../product-specs/prototype-direction.md#お店2026-11-09)にある。

今の村は`Tools/MapAuthoring/forest_layout.py`の`CLEARINGS`の先頭（中心60, 54、半径20×15）にあり、宿屋、家2軒、屋台2つ、噴水、井戸、掲示板などを`FACILITIES`で置いている。絵は草地に馴染ませる古い描き方である。東西の道（`west-spine`と`east-spine`）が村を通り、北へ`north-spoke`（x=50付近から）、南へ`south-spoke`（x=66付近から）が出る。地面は`forest_texture.py`がデザイン案の画素から草、土、小石を組み合わせて作り、石畳の材料はない。

## 対象範囲

- 中心街の平面図（大通り、交差点の広場、建物と小物の位置、道との接続）
- 騎士の描き方での街の設置物: 宿屋、家（2〜3種）、噴水、井戸、掲示板、街灯、樽、木箱、花箱、街の入口
- 屋台とガラクタの露店の、ゲーム用の絵への切り出し
- 大通りと広場の地面
- 地図生成への組み込み、判定、森の確認用Sceneでの確認
- 今のお店の場所を、新しい屋台と露店へ移す

## 対象外

- お店の品揃え、値段、在庫、画面
- 行商人の荷馬車のランダムな出現
- 街の外の目印（野営地、水車小屋など）の描き直し
- 街を安全地帯にするなどのルール
- 宿屋に入る、建物の中

## 実装計画

1. 平面図を決める。大通りの幅と長さ、交差点の位置、建物と小物の位置を`forest_layout.py`の座標で決め、上から見た図にして所有者に見せる。南北の道は交差点へ寄せる。
2. 騎士の描き方で街の設置物を描く。建物は騎士の3倍ほどの高さになり、元の大きさの騎士と同じシートには収まらない。騎士を半分の大きさで置いたシートで描かせ、騎士の倍率で縮める。描けたら騎士と並べて確かめる。
3. 大通りと広場の地面を決めて作る。
4. 切り出しと判定のツールを作る。お店と街の設置物を騎士の倍率で切り出し、足元と判定を一覧で持つ。今の`forest_objects.py`は幅を指定して縮めるので、騎士の倍率で縮める物は別の一覧にする。
5. 地図生成へ組み込む。村の古い設置物を外し、新しい物を置く。お店の場所を新しい屋台と露店へ移す。
6. 森の確認用Sceneで歩いて確かめ、配置を直す。

| 北の通り | x=58.5〜61.5、y=54〜59.5 | 突き当たりに宿屋 |

| 宿屋 | (60, 60) | 幅5.2、高さ5.0 |
| 武器屋、防具屋 | (44, 55.6)、(53, 55.8) | 幅2.7、高さ3.5 |
| 魔法屋、道具屋 | (67.5, 55.8)、(73, 55.6) | 幅2.7、高さ3.9（魔法屋の塔）と3.5 |

- 建物は大通りの北側に並べ、正面を大通りへ向ける。見下ろしの絵では建物が足元より上へ伸びて見えるので、南側に背の高い建物を置くと大通りを隠す。南側は花壇、長椅子、掲示板、井戸など低い物にする。
- 南向きの家を、大通りから4単位以上離して南側に置く案（(46, 44)と(74, 44)）も図に描いた。置くかは所有者が決める。
- 北への道（`north-spoke`）は承認済みなのでそのまま残し、西の2軒の家の間を抜ける脇道にする。南への道（`south-spoke`）は井戸と重なるので、南の入口(60, 43)から出るよう付け替える。西と東の道は大通りの両端につなぐ。宿屋への小道（`inn-walk`）と家への小道は外す。
- 街は東西40単位で、通常Camera（縦14、16:9なら横25）の1.6画面分になる。
- 屋台と露店は、家の3割ほどの幅しかなく小さく見える。イメージ図では家の8割ほどある。描いたときの指示（騎士の肩幅の2倍）より小さく描かれた。街の設置物を描くときに、大きく描き直すか決める。

### 平面図どおりのイメージ図

平面図の位置と大きさで、地面の上に建物や小物を単純な形（壁、屋根、扉）で置いた下書きを作り、騎士とお店の絵を見本にして塗らせた。

- 街全体（48×32単位、1単位を32 pixel）を塗らせると、建物と道の位置は守られたが、騎士と小物が1.5〜2倍に描かれた。大通りは騎士3.6人分の幅のはずが、2.3人分に見えた。
- ゲームと同じ1単位64 pixelで画面1枚分（24×16単位）を塗らせると、騎士は約70 pixelで、家、屋台、露店、掲示板も下書きの大きさのままだった。噴水だけは花壇の輪が付いて一回り大きくなり、図にない木、樽、柵、街灯が足された。
- 大きさを確かめるイメージ図は、ゲームと同じ倍率で描かせる。小さい物が小さく写る縮小図では、生成AIが小さい物を大きく描く。
- 下書きの作り方: 今の地図の地面と自然物を描き、村の古い設置物を外し、平面図の石畳と道、建物の壁と屋根と扉、小物の形を重ねる。今の騎士と屋台と露店の絵は、ゲームの大きさのまま置く。

### 家をお店にする（2026-11-09）

所有者の指示で、北側の4軒の家を個別のお店にした。屋台と露店は外の通りで特別な品を売る。

| 位置 | お店 | 見分け方 |
| --- | --- | --- |
| (44, 55.6) | 武器屋 | 灰色の屋根、剣と斧の看板、武器の棚と金床、鍛冶屋の店主 |
| (53, 55.8) | 防具屋 | 青い屋根、盾の看板、鎧を着せた台と丸盾、防具職人の店主 |
| (67.5, 55.8) | 魔法屋 | 紫の屋根と小さな塔、水晶玉の看板、光る水晶と薬瓶、魔女の店主 |
| (73, 55.6) | 道具屋（案） | 緑の屋根、薬瓶の看板、木箱、樽、袋、薬草 |

- どの店も正面に窓口のカウンターがあり、店主が顔を出す。建物の中を作らずに、買える場所が見て分かる。
- 4軒目は道具屋の案で描いた。屋台が特別な品を売るので、回復薬などの売り場として置いた。役割は所有者が決める。
- 絵は`prop-shophouse-01`である。騎士を同じシートに置かずに描いたので、イメージ図では建物の幅が3.4単位になるよう0.618倍に縮めた。ゲーム用の絵は、騎士と同じシートで描き直す。
- 紫の屋根と魔女の帽子が、今の背景抜き（`forest_objects.key_magenta`）で背景と一緒に抜けた。紫を含む絵は、ほぼ純粋なマゼンタだけを抜く判定で切り出す。
- 4軒を平面図の位置に絵のまま置き、周りだけを塗らせたイメージ図（西半分と東半分）で、通りに並んだ見え方を確かめた。

## Decision Gate

- **南側の建物の向き**: 見下ろしの絵では、建物は正面（南）を見せる。大通りの南側に建物を並べると、正面が大通りの反対を向き、大通りからは背中になる。南側は屋台、露店、井戸、花壇など低い物を中心にするか、背面の絵の建物を描くかを、平面図の段階で決める。
- **街の入口**: イメージ図は南に石壁と門がある。壁と門を置くかは、街を安全地帯にするかと合わせて決める。それまでは門のない入口の目印（アーチや旗）に留める。
- **大通りの地面**: 地形は騎士の描き方の対象外で、今の地面の描き方を守る。石畳を今の地面の描き方で作るか、踏み固めた土の道を広げるかを、試作して決める。
- **街の大きさ**: 通常Cameraは縦14 Unity単位で、画面が16:9なら横は約25単位である。大通りを画面1.5枚分（約36単位）とする案から始め、走って確かめる。

## 組み込み（2026-11-09）

デザインを後で詰める前提で、仮の絵で地図の中心へ組み込んだ。

- お店の家4軒、屋台、露店は`build_town_sprites.py`が`Town/`へ切り出し、`forest_objects.py`の`TOWN_OBJECTS`が足元と判定を持つ。お店の家の判定は窓口と脇の品の幅で、奥行き1単位とする。
- 宿屋は古い村の宿屋の絵を幅333 pixel（5.2単位）へ縮めて使う（`town-inn`）。噴水、井戸、掲示板、樽、木箱も古い絵のままである。
- 石畳は`forest_layout.py`の`PAVED`（大通り、広場、北と南の通り、お店への小道）を、`build_forest_map.py`の`paving`が仮の石の並びと縁石で塗る。地面の描き方の材料に石畳がないための仮である。
- 道: 宿屋と家への小道3本を外し、西と東の道を大通りの両端へ、南への道を南の通りの端`(60, 44)`へつないだ。北への道はそのまま、武器屋と防具屋の間を抜ける。村の`PLAZAS`3つは石畳に置き換えた。
- Scene: 開始位置を広場の南の出口`(60, 47)`へ、ショップの場所を6つのお店の前へ、噴水の回復の場所を噴水の南`(60, 50.8)`へ移した。品揃えは分けておらず、どのお店でも同じショップが開く。
