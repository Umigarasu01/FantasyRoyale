# 片手剣の型の走りと剣の付け方の組み込み

## 目的

所有者が見た目を固めた片手剣の型の走りと、剣の付け方をゲームへ入れる。

完了条件は次のとおり。

- 剣を持って走ると、片手剣の型の胴（剣の腕を下ろし、拳を握った胴）になる。弓や素手の走りは今の胴のままである。
- 剣は「鍔から先」と「柄頭」の2つの絵で、胴の拳の両端へ付く。握りの部分は描かない。緑の拳は重ねない。
- 重ね順が固めたとおりになる。柄頭は胴の下、鍔から先は胴の上である。背面の走りと立ち姿では鍔から先も胴の下で、刃の向きへ3.5 pixel出して鍔を見せる。攻撃中の斜め後ろと背面では、鍔から先を胴の上、頭の下に置く。
- 騎士と革の胴のどちらでも、片手剣の走りが崩れない。
- Test、Scene Builder、資産参照の検査が通る。

## 背景と根拠

所有者は2026-11-08に、走りの上半身も武器種ごとに作ると決めた（[装備と動きの要件](../../product-specs/equipment-and-motion.md)）。見た目は試作を重ねて固めた。経緯は[地面を蹴る走りへの描き直し](bounding-run-cycle.md)の判断記録にある。元絵は`Assets/Art/Generated/ForestLook/`の`hero-run-sword-*`、`hero-body-run-sword-*`、`hero-torso-run-sword-*`である（[生成アセット](../../development/assets/generated-assets.md)）。

## 対象範囲

- `Tools/MapAuthoring/build_hero_frames.py`: 片手剣の型の走りの胴、拳の両端の位置、剣の2つの絵。緑の拳を外す
- `CharacterSpriteAnchors`、`CharacterSpriteView`、`CharacterGearDefinition`、`CharacterSpriteSetDefinition`
- `CharacterSpriteAnimator2D`: 武器種による走りの胴の切り替え、剣の2つの絵と重ね順
- `ForestMapPreviewDebug`: 装備した武器の武器種を体へ渡す
- `ForestMapPreviewDebugSceneBuilder`、EditMode / PlayMode Test
- 革の胴の片手剣の型の走りのシート（生成2回）
- Documentation

## 対象外

- 弓の型の上半身
- 立ち姿と攻撃の胴の描き直し（今の胴で固めた見た目になる）
- 片手剣以外の武器の2つの絵

## 実装計画

1. ツールが片手剣の型の走りの胴を、今の走りの体のコマと同じ位置へ書き出す（`hero-torso-sword-<view>-<index>.png`）。手の位置は`hero-sword-<view>-<index>`として`anchors.json`へ書く。
2. ツールが全てのコマで、騎士の胴の拳を剣の向きに沿って測り、拳の中心から刃の側の端と柄頭の側の端までの距離（`mainHandFront`、`mainHandBack`）を書く。横の走りと立ち姿は前腕を除いた拳だけで中心を測り、背面の走りと立ち姿は3.5 pixel刃の向きへ出す。
3. ツールが剣の絵を鍔から先（`sword-rot-<index>`）と柄頭（`sword-pommel-rot-<index>`）に分けて24方向へ回す。緑の拳の書き出しを外す。
4. ゲームが武器種ごとの走りのコマを持ち、装備した武器種の走りを使う。剣の2つの絵を拳の両端へ置き、固めた重ね順にする。
5. Scene BuilderとTestを合わせる。
6. 革の胴の片手剣の型の走りを描き、ツールで切り出す。
7. 一時複製で組み立て、Testと撮影で確かめ、本体へ戻してDocumentationを更新する。

## 判断記録

- 片手剣の型の体のシートは、今の走りの体のシートを描き直した物なので、コマの位置は今の体のコマの置き方をそのまま使う。脚は全ての武器種で共通なので、こうすると今の脚の部位がそのまま合う。
- 頭の位置は今の走りの値を使う。試作で所有者が確かめた組み方と同じである。
- 拳の両端は騎士の胴で測り、全ての胴の部位が共有する。手の位置と同じ扱いである。
- 利き手の位置は、剣入りの絵の握りの点の近くにある騎士の胴の手袋の中心へ変えた。拳の両端を同じ拳から測るためである。攻撃は胴の部位の拳で測るので、素手の体の拳から測った前の値と1 pixelほど違う。
- 剣の鍔から先は前と同じ`sword-rot-<index>`の名前で書き出し、Assetの参照を保つ。柄頭は新しい`sword-pommel-rot-<index>`である。
- 背を向けて走るときの鍔から先は、前は体の後ろ（足の下）だったが、固めた試作のとおり足の上、胴の下にする。攻撃中に背を向けたときの残像も、鍔から先と同じ胴と頭の間に置く。
- 緑の拳（`hero-fist-01.png`、`build_fists`、`GetHeldFist`）は外した。拳は胴の部位の絵そのものになる。弓のように分けない部品は、今までどおり体の拳（`Hand/`）を重ねる。
- 革の胴の片手剣の型の走りは、騎士の片手剣の型の胴を参照画像にし、革の共通の走りの胴を見本に着替えさせた（`gpt-image-2.5-sunburst`、medium、2回）。

## 検証

- ツールの出力だけで走り、立ち姿、攻撃を組み、固めた試作と同じ見た目になることを確かめた。
- 革の胴を入れる前の一時複製で、EditMode 324件中323件成功（失敗は革の胴に片手剣の型の走りがまだないことを示すTest）、PlayMode 37件中32件成功（失敗の5件は従来と同じStudyAのSetUp失敗）。実画面の撮影で、横、正面、背面の走りと8方向の攻撃を確かめた。
- 革の胴を入れた一時複製で、EditMode 324 / 324成功、PlayMode 37件中32件成功（失敗の5件は従来と同じStudyAのSetUp失敗）。革の片手剣の型の胴は騎士の胴と輪郭が0.92以上重なった。
