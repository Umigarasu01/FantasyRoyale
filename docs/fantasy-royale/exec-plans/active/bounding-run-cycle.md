# 地面を蹴る走りへの描き直し

## 目的

騎士の走りを、歩幅が大きく、両足が地面から離れる瞬間のある6コマの走りへ描き直す。走る速さ6のまま、足が地面を送る速さと体の進む速さを合わせ、地面を踏みしめて見えるようにする。

完了条件は次のとおり。

- 横と斜めの走りで、地面に着いた足が1コマに後ろへ動く量と、1コマに体が進む距離が近い。差はツールの出力と計算で示す。
- 1秒の歩数が今の6.5歩より少なく、落ち着いた足運びに見える。
- 騎士、革の胴、布巻きサンダル、鉄の重靴のどの組み合わせでも、走りと走りながらの攻撃が崩れない。
- 武器の手の位置、拳、影、砂ぼこり、跳躍が6コマでも今までどおり動く。

## 背景と根拠

所有者の確認で、走りが地面から浮いて見え、足運びが速すぎるように感じられた。計算すると、横の走りでは地面に着いた足が1コマに15 pixel、1歩で0.47マスしか地面を送らない。毎秒13コマの足運びが表す速さは約3マス毎秒で、実際の6の半分だった。足は1秒に6.5歩と忙しく動くのに、地面はその倍の速さで流れていた。

遅くすると滑りが増え、足だけ速くするとせわしなく、速さを3へ下げると遅すぎる。所有者は、歩幅を大きく取った走りへ描き直す案を選んだ（2026-11-07）。経緯は[森の確認用Scene](../../design-docs/scenes/forest-map-preview-debug-scene.md)の装備の見た目にある。

## 対象範囲

- 騎士の走りのシート（剣と盾を持った絵、持ち物のない絵、胴、足）と斜めのシート
- 革の胴、布巻きサンダル、鉄の重靴の走りのシート
- `Tools/MapAuthoring/build_hero_frames.py`の走りのコマ数、両足が浮くコマの高さ、縮尺
- Scene Builderの走りのコマ数と、`CharacterSpriteAnimator2D`の砂ぼこりを出すコマ
- 足運びの速さ（体の定義の`Frames Per Second`）

## 対象外

- 走る速さ6の変更
- 立ち姿、攻撃、止まって振るときの踏み込みの絵
- 正面と背面の走りで、足を縦に動かして地面を送る描き方。足元の位置の扱いを変える必要があるので、今回は足を揃える高さの差で歩幅を見せるだけにする

## 実装計画

1. 6コマの走りを、1歩につき着地、体重を乗せて足が体の下を通る、両足が浮くの3コマとする。1周は2歩で6コマである。
2. 剣と盾を持った騎士の走りのシートを1枚試作し、横の走りの足が1コマに後ろへ動く量を測る。足運びの速さは、走る速さ6を1コマに動く量で割って決める。
3. **Decision Gate:** 試作の見え方と計算を所有者に見せ、残りの生成へ進むか決める。
4. 残りのシートを、今と同じ順に編集で作る。剣と盾を持った絵、持ち物のない絵、胴と足、革、サンダルと重靴の順である。
5. ツールとScene Builderを6コマに対応させる。両足が浮くコマは足元を少し持ち上げる。
6. 複製で組み立て、撮影とTestで確かめ、Documentationを更新する。

- 所有者の確認で、握りがおかしいと指摘された。拳は立てた柄を握る形のままで、下げた剣が拳の下にぶら下がって見えた。拳を回す案は形が崩れた。斜め後ろの立ち姿の拳は同じ角度（299.2度）の剣を握っているので、ツールはその拳を各コマの手の位置へ移して使う。角度も同じ立ち姿から取るようにし、`RUN_ANGLE_LIKE`は`RUNS_HELD_AS_IDLE`へ置き換えた。手の位置は描かれたままである。
- 所有者の提案で、剣の絵を鍔までにして拳にくっつけた。ツールは剣の絵の最初に広い行を鍔の縁とし、そこから先だけを24方向へ回す。利き手の位置は、拳の中心から剣の向きへ進んで拳の絵が終わる所にする（多くは拳の中心から7 pixelほど）。拳が体の陰で見えない振りの3コマは、剣入りの絵の刃が始まる所を使う。柄頭が拳からはみ出すことがなくなり、剣は前より3 pixelほど外へ出る。
- 所有者の確認で、拳を球と見立てれば柄が刺さって見えないと握っているように見えないと指摘された。描かれた拳は、別の角度の柄や鍔の切れ端と、柄の通った穴を含んでいて、中心も握りの点から最大7 pixelずれていた。ツールは利き手の拳を、手の色の最も大きなまとまりの穴を埋めた玉に描き直し、玉の中心を柄が通るよう、鍔を玉の刃側の端に置く。剣の絵は柄頭まで戻した。玉の差し渡しは多くが7 pixelほどで、柄（鍔から柄頭まで約10 pixel）は多くのコマで反対側から2〜3 pixel出る。斜め後ろの走りの拳は、玉にすると向きの違いがなくなるので、立ち姿の拳を移す扱いは外し、角度だけを立ち姿から取る。
- 所有者の確認で、玉の拳は形が崩れていると退けられ、剣を握り込んで見えるまで改善するよう指示された。測ると、剣入りの絵の握りの点は、胴の絵（素手の体）が描く拳から4〜12 pixel離れていて、腕の先の拳と、剣を握る拳が別々に描かれていた。ツールは走りと立ち姿で、剣を素手の体の拳に持たせる。柄の中央（剣の絵の上から21%）をその拳の中心に置き、同じ拳を切り出して柄の上に重ねる。剣入りの絵からは角度だけを取る。玉の拳と鍔からの剣は外した。
