# 黒漆のHUD

## 目的

[UIのデザイン方針](../../product-specs/art/ui-design.md)で決めた「飾りのない黒漆」のHUDを、Unityで実際の画面に出す。今のゲームにあるデータで表せる物から作り、森の確認用Sceneで遊びながら見られるようにする。

完了条件は次のとおり。

- 森の確認用Sceneの左上に、黒漆の枠に入ったハートとコインが出る。
- ハートはHPに合わせて満ち、欠け、空になる。コインは増減に合わせて変わる。
- お店、宝箱、泉の前でEキーの吹き出しが、その物の上に出る。
- HUDの絵はリポジトリのツールで作り直せる。
- HPからハートを決める規則と、HUDが画面の値に追従することをTestで確かめる。

## 背景と根拠

2026-11-09に、所有者はUIの見た目を飾りのない黒漆に決め、HPはハート式、自分の顔の絵は出さないとした。続けて「HUDを作る」とした。

今の`ForestMapPreviewDebug`は、OnGUIの確認用の文字（HP、コイン、装備、操作、座標、FPS、Seed、直前の出来事）を左上に並べ、その下に「全装備を開く」のボタンを置く。お店の画面もOnGUIである。uGUI（`com.unity.ugui` 2.0.0）は入っているが、まだどこでも使っていない。描画はBuilt-inで、TextMeshProの基本Asset（Essential Resources）は取り込んでいない。

ゲームにあるデータは次のとおり。

| HUDの要素 | 今のデータ | この計画 |
| --- | --- | --- |
| ハート | `CharacterHealth`（最大100の整数） | 作る |
| コイン | `ForestMapPreviewDebug.Coins` | 作る |
| Eキーの吹き出し | お店、宝箱、泉の届く距離 | 作る |
| 育成フェーズの残り時間 | なし | 対象外 |
| 小さな地図、他のプレイヤー | なし | 対象外 |
| 装備の枠（J、K） | 武器1つが通常と特殊の2つの動きを持つ。武器のアイコンの絵はない | 対象外 |
| 回復薬 | 買うとその場で回復し、持ち物にならない | 対象外 |

## 対象範囲

- HUDの絵を作るツール`Tools/UiAuthoring/build_hud_sprites.py`と、その出力`Assets/Art/Generated/Hud/`
- HUDの絵の取り込み設定を決めるEditorの処理
- uGUIでHUDを組む本番側のAssembly（ハート、コイン、Eキーの吹き出し）
- HPからハートを決める純C#の規則とEditMode Test
- 森の確認用Sceneへの組み込み、確認用の文字の移動、PlayMode Test
- 仕様、設計、手順の文書

## 対象外

- 残り時間、小さな地図、他のプレイヤーの一覧、装備の枠、回復薬の枠（元になるデータがない）
- お店の画面、全装備の確認用画面の作り直し
- 日本語のフォント（今回のHUDは数字だけを使う）
- 出来事を知らせる文字（今は確認用の文字の`LastMessage`のまま）
- 探索Preview（`BattleRoyaleExplorationPreviewDebug`）への組み込み

## Decision Gate

- ハートの数え方（ハート1つ分のHP、欠け方、最初と最大の数）は所有者が決める。決まるまでは、仮の規則を確認用Sceneの定数に置く。

## 実装計画

1. 絵: PILで4倍に描いて縮める。枠は9分割で伸ばす黒漆と細い金の縁。ハートは満ち、半分、空の3枚。コイン、Eキー、吹き出しの先の三角。画面の基準は1920×1080で、絵はその2倍の解像度で作る。
2. 取り込み: `Assets/Art/Generated/Hud/`のPNGにSprite、Bilinear、Mipmapなし、無圧縮、Pixels Per Unit 200を当て、枠には9分割の境界を付ける。
3. 本番側: `FantasyRoyale.Gameplay.Hud`を新しく作る。`HeartGauge`（純C#の規則）、`HudSkin`（絵をまとめるScriptableObject）、`GameHud`（uGUIのCanvasを組み、値を受け取って表示する）を置く。HUDはゲームの状態を読まず、渡された値だけを表示する。
4. 確認用Scene: `ForestMapPreviewDebug`がHUDを作り、毎Frame、HP、コイン、届く物の位置を渡す。確認用の文字とボタンは左下へ移す。Scene Builderが`HudSkin`を作って渡す。
5. Test: `HeartGauge`のEditMode Testと、森の確認用SceneのPlayMode Test（ハート、コイン、吹き出し）。
6. 実際の画面を撮って、サンプルの絵と比べる。
7. 文書を更新する。

## 判断記録

- 2026-11-09: 今のゲームにデータがある物（ハート、コイン、Eキー）だけを作る。データのない要素を偽の値で出さない。
- 2026-11-09: 絵は画像生成でなく、PILで図形として描く。9分割の枠や3段階のハートは、形と縁の太さを正確に揃える必要があり、生成した絵を切り出すより確実で、作り直しもしやすい。
- 2026-11-09: 文字はuGUIの`Text`と組み込みの`LegacyRuntime.ttf`で描く。HUDは数字だけなので、TextMeshProの基本Assetや外部のフォントを今は取り込まない。Eキーの文字は絵に描き込む。
- 2026-11-09: 仮のハートの規則は、ハート1つを20 HP、半分ずつ欠ける、とする。最大100 HPでハート5つになる。敵の接触は10、回復は30なので、今の値は半分のハートで割り切れる。HPが残っていれば最低でも半分のハートを見せるため、半分の単位へ切り上げる。
- 2026-11-09: 黒漆の地とハートの空の地を不透明にした。最初は地を93%の不透明度にしたが、このProjectは線形の色空間で描くため、暗い半透明の色の下で草が緑に透け、黒漆に見えなかった。
- 2026-11-09: 吹き出しの三角の先は、お店と回復の場所では立つ位置の1.6上、宝箱では箱の1.0上に置く。物の上の端に出すには物ごとの高さが要るので、今はしない。お店では店の人の顔に少し掛かる。
- 2026-11-09: 確認用の文字と「全装備を開く」は左下へ移した。ショップと全装備の画面はOnGUIのままにした。
- 2026-11-09: 所有者がコインがコインらしくないとした。平らな金の円をやめ、刻みの入った側面の厚み、縁の輪、打ち出しの王冠を描いた金貨にした。王冠と厚みが見えるよう、画面上の大きさを26から30 pixelにした。森のPlayMode 26 / 26成功を確かめた。
- 2026-11-09: 所有者が正面でない方がよいとした。縦に回した向き、寝かせた向き、斜め4分の3を作って比べ、ゲームの大きさで厚みと王冠が一番見える斜め4分の3にした。- 2026-11-09: 所有者がもっとリアルなコインにとした。図形で描く方法では金属の映り込みと細かい浮き彫りに限りがあるので、金貨だけを画像生成（`gpt-image-2.5-flare`、high、透明な背景、2枚のうち1枚目）で描き、ツールが切り抜いて60 pixelへ縮める形にした。元の画像と記録は`Tools/UiAuthoring/Inputs/hud-coin-source.*`にある。図形で描いた金貨の処理は外した。
- 2026-11-09: 所有者がハートもコインに揃えるとした。赤いエナメルのハートを金の縁で囲んだ宝石を画像生成（`gpt-image-2.5-flare`、high、透明な背景、2枚のうち2枚目）で1枚だけ描き、ツールが色でエナメルを見つけて、空と半分のハートを黒いガラスに塗り替えて作る。3種類の金の縁が同じ絵から来るので、形がぴったり揃う。図形で描いたハートの処理は外した。
- 2026-11-09: 所有者がもっとガラスの中に入っている感じにとした。透明なガラスの中に赤い芯を封じ込めたハートを生成し直し（2枚のうち2枚目。赤い芯の周りの透明なガラスの帯が広く、HUDの大きさでもガラスと分かる）、空のハートは芯だけを暗くして、ガラスの帯と映り込みを残す形にした。
- 2026-11-09: 所有者が一旦この見た目で進めるとし、文字にピクセルフォントを試したいとした。DotGothic16とPixelMplusを取り込んで比べ、所有者がPixelMplus12 Boldに決めた。`HudSkin`が数字のフォントと元の格子（12 pixel）を持ち、`GameHud`が`PixelFontSizing`で画面上の大きさを格子の整数倍に合わせ直す。Canvasは`pixelPerfect`にした。1080p（24 pixel）と900p（fontSize 29、画面上24 pixel）で撮って、ドットの太さが揃うことを確かめた。EditMode 337 / 337、森のPlayMode 26 / 26成功。

## 検証

- 所有者の開いているEditorでUnity MCPから実行した。EditMode 330 / 330成功（`HeartGaugeTests` 4件を含む）。PlayModeの`ForestMapPreviewPlayModeTests` 26 / 26成功（`ForestMap_HudFollowsHealthCoinsAndUseTargets`を含む）。他のPlayMode Testは実行していない。
- HUDの絵7枚に取り込み設定（PPU 200、Bilinear、Mipmapなし、枠の9分割の境界32）が当たったことを確かめた。
- 森の確認用Sceneを作り直し、屋台の前でHP 70、コイン24の状態を1920×1080で撮った。左上の枠にハート3つ半とコイン24が出て、屋台の上に吹き出しが出た。Screen Space OverlayのCanvasは`capture_game_view`に写らないため、実行中だけCanvasをScreen Space Cameraへ替え、一時停止して`screenshot`で撮った。
- Knowledgeの検証を通した。

## 完了結果

- 森の確認用Sceneに、黒漆の枠のハートとコイン、Eキーの吹き出しが出るようになった。
- 本番側のAssembly`FantasyRoyale.Gameplay.Hud`（`HeartGauge`、`HudSkin`、`GameHud`）、絵を作る`Tools/UiAuthoring/build_hud_sprites.py`、取り込み設定の`HudSpritePostprocessor`を足した。
- 残る事項: ハートの数え方のDecision Gate、残り時間、小さな地図、他のプレイヤーの一覧、装備と回復薬の枠、ショップと全装備の画面、日本語のフォント、出来事を知らせる文字、探索Previewへの組み込み。吹き出しを物の上の端へ出すこと。
