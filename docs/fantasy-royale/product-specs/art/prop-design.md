# 設置物のデザイン規約

状態: **案**。2026-11-08に宝箱の1点で確かめた。所有者の確認を待っている。

マップに置く物を、騎士と同じ描き方で揃えるための決まりである。対象は宝箱、敵、看板、商人、建物、小物などの設置物とする。地面と地形（草地、道、水、森の壁、崖）は対象にせず、[森マップの画作り基準](../../exec-plans/completed/forest-look-lock.md)の描き方のままとする。

## 基準は騎士

騎士の立ち姿は、正面で高さ72 pixel、幅49 pixel、横向きで幅31 pixelである。設置物のドットの粗さ、線、色、角度、大きさは、全て騎士に合わせる。

## ドットの粗さ

- 64 PPUで、絵の1ドットを画面の1 pixelとする。騎士と同じである。
- 騎士は、元絵で1ドットを約7.4 pixelで描き、0.135倍に縮めて作っている。設置物も、元絵の1ドットが縮めた後に1 pixelになるよう、騎士と同じ倍率で縮める。
- 描いた後で拡大も縮小もしない。ドットが騎士より細かく、または粗くなる。大きさを変えるときは、騎士との比を指示し直して描き直させる。
- 1 pixelの線は、輪郭と金具の縁などに限る。木目や汚れを1 pixelの点や線で描かない。

## 線

- 外周を、黒に近い1 pixelの線で閉じる。
- 内側の境目は、暗い同系色の線で分ける。

輪郭の明るさ（0〜255）の中央値は、騎士が7、新しい宝箱が4である。今の宝箱は35の茶色で、草地に溶けて見える。

## 陰影と質感

- 素材ごとに3〜4段の明暗と、小さな光を置く。光は左上から当てる。
- 形は大きな色の塊で見せる。ざらつき、ノイズ、ディザ、細かい傷を入れない。
- 苔、土汚れ、草を絵に付けない。

## 色

騎士と同じ彩度にする。木は騎士の手袋と靴の茶、金具は縁取りの金、鉄は兜の銀を目安にする。

## 角度

騎士と同じく、正面を少し上から見下ろす。箱の蓋や屋根の上面が見えるようにする。指示しないと真横から見た平たい絵になる。

## 影と地面

地面へ落ちる影を絵に描かない。騎士も描いていない。地面、草、台座も絵に含めず、背景は透過にする。

## 大きさ

騎士との比で指示し、描けた絵を騎士の倍率で縮める。

| 物 | 幅×高さ（pixel） | 騎士との比 |
| --- | --- | --- |
| 宝箱（閉） | 38×33 | 上端が騎士の帯の高さで、騎士の半分弱。幅は肩幅より少し狭い |
| 宝箱（半開き） | 36×43 | 蓋が45度ほど上がる |
| 宝箱（開いて空） | 36×45 | 閉じた箱の上へ、開いた蓋が出る |
| 開く瞬間の光 | 39×18 | 半開きの蓋の下から横へ飛び出す |
| 中の光 | 31×22 | 箱の内側と蓋の裏を照らす。蓋より上へ出ない |
| 立ち上る粒 | 21×23 | 箱の口から蓋の上端あたりまで |
| 横へ広がる光 | 48×18 | 箱の両脇へ6 pixelずつはみ出す |
| 光の柱 | 8×45 | 箱の奥の縁から、開いた蓋の上端より26 pixel上まで伸びる |

## 宝箱の状態と動き

宝箱は、閉じた箱、開いて何か入っている箱、開いて空の箱の3つの状態を持つ。開けた後に中身が残り、後から来た人も漁れる形を想定している。漁る仕組みはまだ作らない。

| 状態 | 箱の絵 | 光 |
| --- | --- | --- |
| 閉じている | 閉じた箱 | なし |
| 開ける（1回だけ） | 半開きの箱（1コマ） | 開く瞬間の光 |
| 何か入っている | 開いた箱 | 中の光と、レア度の飾り。12コマを繰り返す。1コマ100 ms |
| 空 | 開いた箱 | なし |

何か入っている箱の光は、中の光を土台にし、レア度が上がるほど飾りを足す。上のレア度は、下のレア度の飾りも全て持つ。色だけでなく派手さでもレア度が分かり、遠くからでも伝説を見落とさない。

| 色 | 中の光 | 立ち上る粒 | 横へ広がる光 | 光の柱 |
| --- | --- | --- | --- | --- |
| 白 | ○ | | | |
| 青 | ○ | ○ | | |
| 紫 | ○ | ○ | ○ | |
| 金 | ○ | ○ | ○ | ○ |

- 中身の形は描かない。光の色と飾りで、中に残っている物のレア度を表す。宝箱の中身は通常、レア、伝説級のアイテムの抽選で、錆びた遺物も出るので、金貨のような特定の物に見せない。どの色がどのレア度かは、アイテムのレア度を決めるときに合わせる。
- 光は箱の内側から出し、箱の内側と蓋の裏を照らす。箱と切り離して箱の上に光の筋だけを重ねると、光が箱から浮いて見えた（2026-11-08に所有者が指摘）。
- 中の光は、空の箱の木の色を残し、明るくなった分だけ光の色を足す。いちばん明るい芯は白に近い光の色にする。色相を丸ごと塗り替えると、箱の中が色の液体で満ちたように見え、白は紙が詰まったように見えた。
- 明るい光は箱の中の1か所にまとめる。開いた箱は蓋の裏と箱の中の2つの面を持ち、間を箱の奥の縁が横切る。両方を同じ明るさで照らすと、光が上下2段に見えた（所有者が指摘）。蓋の裏は下から淡く照らされるだけにし、光の色の強さを奥の縁のすぐ上で0.45、蓋の上端で0.15にする。白い芯は奥の縁より下だけに置く。
- 光の柱は、箱の中の光から立ち上がるよう、根元を奥の縁まで伸ばす。描かれた柱は蓋の裏の上で終わっていて、蓋の裏を暗くすると柱が浮いて見えた。
- 飾りは、明るさと彩度の比を残して色相だけを変える。芯は彩度がほぼないので白のまま残る。ゲーム側で絵の全体に色を掛けると芯まで染まって光に見えにくいので、色ごとの絵を用意する。
- 光は透かさない。外側を半透明にすると、緑の地面と混ざって青が青緑に、金が黄土色にくすんだ。
- 全ての箱の絵と光を同じ大きさの画像（60×96 pixel）に置き、箱の胴の下端の中央を画像の下端の中央に揃える。状態が変わるときは絵を差し替え、光は同じ位置に重ねる。光の柱と横へ広がる光が収まる大きさである。
- 光の動きは、静止画で決めた絵の形を保ったまま、動かす、切る、点けて消すことで作る。新しく描かせると、コマごとに形が変わる。

| 部分 | 動き |
| --- | --- |
| 中の光 | 光の色の強さが0.82倍から1倍の間で1周に1回強まって弱まり、白い芯も一緒に広がって縮む |
| 立ち上る粒 | 粒を1つずつ、箱の中の光（箱の下端から21 pixel上）から1コマに3 pixelずつ上げ、蓋の上で消す。出る時と消える時のコマは1点だけにする。粒ごとに出る時をずらす |
| 横へ広がる光 | 筋ごとに、箱から出る根元を残して、描いた長さの0.55倍から1倍の間で伸び縮みさせる。筋ごとに時をずらす。6 pixel以下の点は、伸び縮みの代わりに点けて消す |
| 光の柱 | 先端を0から4 pixelの間で上下させ、てっぺんの粒を先端と一緒に動かして瞬かせる |

レア度の色を他のプレイヤーにも見せるかは、まだ決めていない。

## 描かせ方

1. 1536×1024のマゼンタの画像を作り、騎士の立ち姿のシート`hero-idle-01.png`の左の列（正面）を、元の大きさと位置のまま左の列へ置く。真ん中と右の列は空ける。
2. この画像を参照にして、OpenAI Image APIのeditで空いた列へ描かせる。騎士はそのまま残させる。描き方の指示は下の決まり文句を使い、物と大きさの指示だけを変える。
3. マゼンタを抜き、描かれた騎士の高さを測る。元の騎士は530 pixelなので、0.135×530÷(描かれた騎士の高さ)の倍率で物を縮める。縮め方は騎士と同じ`Tools/MapAuthoring/build_hero_frames.py`の`shrink`（BOXで縮め、透明度150で二値にする）を使う。
4. 森マップの地面の上へ騎士と並べ、等倍と3倍で見比べる。

騎士を同じ画像に描かせるので、ドットの粗さと大きさの比が騎士に揃う。

同じ物の別の状態は、描けたシートを参照にして、騎士を残したまま描き直させる。開いた空の箱は、金貨入りの開いた箱から中身を抜いて描かせた。半開きの箱は、閉じた箱を参照にすると2回とも蓋が上がらず、開いた箱を参照にして「蓋が45度ほど上がる」と指示すると描けた。目指す形に近い状態の絵を参照にする。

### 輪郭のない光や効果

宝箱の中身の光のように、輪郭がなく別の絵として重ねる物は、次のように取り出す。

1. 1枚のシートに、空の箱と、同じ箱から光が出ている絵を並べて描かせる。光は白と淡い黄の2〜3段で、輪郭なしと指示する。
2. 2つの箱を足元の位置で揃えて縮め、光の絵の方で明るく、空の箱にはない画素を光とする。金具の差から出る4 pixel未満の点は消す。
3. 光は縮める前に、背景のマゼンタと混ざった淡いピンクの画素を消す。縮めるときは透明な部分の色を混ぜない。輪郭がないので、混ぜると縁が黒や紫に濁る。
4. 色は、明るさと彩度の比を残して色相だけを変える。芯は彩度がほぼないので白のまま残る。

開く瞬間の光は、この方法で半開きの箱のシートから取り出した。閉じた箱の継ぎ目から漏れる光も試したが、縮めると細切れの線になり、光に見えなかった。

中の光と飾りは、次の2枚から取り出す。

1. 騎士、空の箱、中が光る箱のシート（`prop-chest-04`）。空の箱と中が光る箱の差が中の光で、空の箱が開いた箱の絵になる。
2. 中が光る箱を同じ大きさで4つ並べた画像を参照にして、2〜4番目に飾りを足させたシート（`prop-chest-05`）。1番目との差が飾りである。騎士がいないので、箱の幅を1枚目の箱に合わせて倍率を決める。

### 光だけを描かせたGIF（使わない）

`gpt-image-2.6-sunburst`の画像編集でGIF（出力形式gif、6コマ、1コマ100 ms、512×512）を描かせると、「光だけを動かし、箱は描かない」という指示で、透明な背景に光だけが返った。コマ同士はつながり、筋の伸び縮みと粒の瞬きも描けた。ただし箱と別に描いた光は、箱の上に貼ったように浮いて見えたので使わない。0.11倍では筋の隙間が埋まって白い塊になり、0.1倍で筋が分かれて見えた。今の光の動きは、描いた形をコードで動かして作っている。

### 動きの確かめ方

動きのプレビューは、色が欠けない形式（可逆圧縮のWebP）で書き出す。GIFは使える色が256色なので、草の緑に色を取られ、青が灰緑に、紫がピンクに見えた。

### 描き方の決まり文句

```text
Style rules, taken from the knight:
- A continuous near-black outline, one dot thick, around the whole silhouette.
- Flat cel shading: 3 or 4 clean tones for each material plus a small bright highlight. Light comes from the upper left.
- Clean chunky clusters of dots. No noise, no grain texture, no dithering, no scratches.
- The same saturated colours as the knight: warm brown wood like the knight's leather gloves and boots, shiny gold like the knight's trim, bright steel grey like the helmet.
- The same slightly-from-above three-quarter front view as the knight.
- Bold, simple and readable shapes with few details, like the knight.
```

宝箱で使ったPrompt全文は`Assets/Art/Generated/ForestLook/`の`prop-chest-01.json`から`prop-chest-05.json`と`prop-chest-light-01.json`にある。

## 確かめたこと

2026-11-08に、宝箱の閉じた絵と開いた絵を描き、森マップの地面の上で騎士と並べて見比べた。線、ドットの粗さ、彩度は騎士と揃った。低画質の下書きでは箱を真横から見た平たい絵になり、上面が見える角度を指示すると直った。

同じ日に、開いて空の箱と中身の光を描き、3色の光を重ねて等倍と3倍で見比べた。等倍でも3つの状態とレア度の色は見分けられた。光の縁が紫に濁った分は、ピンクの画素を消して透明部分を混ぜずに縮めると直った。伝説の金は、色相40度では薄い橙に見え、46度で彩度を上げると金に見えた。

続けて、半開きの箱、開く瞬間の光、揺らめく光の6コマを作り、白、青、紫、金の4色で、閉じる、開ける、揺らめくの流れを地面の上で見比べた。4色は等倍でも見分けられた。白は外側に色を残しすぎると金に近づくので、白の彩度は0.4倍、金は色相44度で3倍にした。

所有者は、揺らめく光が箱から浮いて見えると指摘した。中が光る、光の柱、立ち上る粒、縁の光、きらめき、低く広い光の6案を箱と一緒に描いて並べ、所有者は中が光る案を土台にレア度で飾りを足す形を選んだ。4段階を地面の上で等倍と3倍で見比べ、等倍でも見分けられ、金の柱は遠くからでも目に入った。さらに所有者の指示で、上のレア度に下のレア度の飾りも入れる形にした。光が2段に見えるという指摘を受け、蓋の裏の光を弱めて箱の中の光を1つにまとめ、光の柱の根元をそこまで伸ばした。続けて、4色の光に12コマの動きを付け、閉じる、半開き、開いて光が動く流れを地面の上で確かめた。

箱と光は`Tools/MapAuthoring/build_chest_frames.py`が書き出す。使い方は[Asset導入・生成Workflow](../../development/asset-workflow.md#騎士に合わせた宝箱)にある。ゲームへの組み込みとUnityでの表示は、まだ確かめていない。

## 今の設置物との差

今の宝箱、敵、建物は、草地に馴染ませる描き方（茶の柔らかい輪郭、ざらつき、苔）で描いた。今の宝箱は74×59 pixelで、騎士の肩幅より広く、高さは騎士の8割ある。他の設置物を描き直すかは、物ごとに決める。
