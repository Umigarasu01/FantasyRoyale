# 所持品

状態: **案**。2026-11-11に所有者が出した想定を整理し、同じ日に所有者が武器と魔法の決まりを、2026-11-13に魔法とアイテムの操作、MP、重ねないこと、開いている間も動けることを決めた。性能、値段、入手方法は範囲外で、未確定である。

所持品は、着けている装備、武器にはめた魔法、カバンの中のアイテムの3つである。コインは所持品に含めず、今のままHUDに数だけを出す。

画面での見せ方は[UIのデザイン方針](art/ui-design.md#所持品の見せ方)に、実装の計画は[所持品と魔法のExecPlan](../exec-plans/completed/inventory-and-magic.md)にある。

## 決まったこと（2026-11-11と13、所有者）

- 武器は、メイン武器とオフハンドの装備に分ける。両方を1つで埋める一体の装備もある。
- 防具は頭、胴、足に分ける。いくつかの部位を1つで埋める一体の装備もある。
- 技は武器ごとの固有の物とする。付け替えない。
- 魔法は武器の魔法の枠（スロット）にはめる。枠の数は武器によって違う。
- オフハンドは、当面ボタンを持たない。
- アイテムは5個ほど持てる。カバンで増える。2026-11-13に、数字キーで使う使用枠と、しまっておくカバンを分けた（[使用枠とカバン](#使用枠とカバン)）。
- 魔法は、選んでいる物を唱えるキーと、次の魔法へ切り替えるキーの2つで使う（2026-11-13）。
- アイテムも含めて、キーボードで操作しやすいキーの配置にし、[操作](#操作)の表の配置に決めた（2026-11-13）。技はQ、魔法はE、魔法の切り替えはR、アイテムは数字キーで使う。
- 魔法はMPを使う（2026-11-13）。
- 同じ物を1つの枠に重ねない。1つの物が1つの枠を使う（2026-11-13）。
- 持ち物の画面と店の画面を開いている間も、騎士は動ける（2026-11-13）。
- 残りの決めることは、実装して試しながら調整する（2026-11-13）。

最初の想定では、武器ごとに技の枠もあり、技も着け替える形だった。所有者が、技は武器ごとの固有に変えた。魔法の操作は、2026-11-13に一度、枠ごとにキーを対応させるとしたが、同じ日に唱えると切り替えの形に戻した。

## 枠の一覧

| 区分 | 枠 | 入る物 | 一体の装備 |
| --- | --- | --- | --- |
| 武器 | メイン武器 | 剣など、通常攻撃と固有の技を決める武器 | 弓のような両手の武器は、メイン武器とオフハンドを1つで埋める |
| 武器 | オフハンド | 盾など | 同上 |
| 防具 | 頭、胴、足 | 部位ごとの防具 | ローブは胴と足を、全身の鎧は頭から足までを1つで埋める |
| 魔法 | 武器ごとの数（0もある） | 魔法 | なし |
| 使用枠 | 5（数字キーの1〜5） | 回復薬などの使う物。下の[使用枠とカバン](#使用枠とカバン)を参照 | なし |
| カバン | 6から（カバンで増える） | それ以外の物と予備の使う物 | なし |

- 一体の装備が埋めた枠は、空でなく同じ物で埋まって見せる。
- 一体の装備を着けると、埋まる枠に着けていた物は外れてカバンへ入る。
- ローブのように腰をまたぐ形は足と胴に分けられないと、[装備と動きの要件](equipment-and-motion.md#足胴頭の分割の検討)で分かっている。一体の防具はその受け皿になる。
- 両手の武器はオフハンドを諦める分、強さか魔法の枠の数で釣り合わせる（案）。

## 武器

- メイン武器が、通常攻撃と固有の技を決める。
- 固有の技は武器を作るときに決め、カバンにも入らず、外せない。1つの武器に1つとする（案）。今の装備の特殊Actionの枠が、そのまま固有の技に当たる。
- オフハンドは、守りなどの数値だけを持つ。当面ボタンも魔法の枠も持たない。

## 魔法

- 魔法は、はめる前はカバンに入る物である。手に入れ方は宝箱や魔法屋などが考えられるが、決めていない。
- 魔法を唱えるとMPを使う。MPが足りない魔法は唱えられない（2026-11-13、所有者）。
- はめた魔法は武器と一緒に動く。武器をカバンへしまっても、入れた魔法は武器に入ったままである。
- カバンの魔法を使うと、メイン武器の空いた魔法の枠へ入る（案）。空きがなければ、持ち物の画面で入れ替える。

### 枠の数が武器で違うことへの備え

魔法の枠の数は武器ごとに違い、0の武器もある。どの数でも、画面と操作を作り替えずに済むよう、次の決まりで作る（案）。

1. **数は武器の数値にする。** 武器ごとに魔法の枠の数を持たせ、0を許す。画面、操作、保存の全てを、その数から作る。2つや4つのような決まった数を前提にしない。
2. **入れた魔法は武器の1本ごとに持つ。** 同じ剣が2本あれば、入っている魔法は別々である。武器の定義でなく、手に入れた1本ごとの持ち物として扱う。持ち替えで枠の数が変わっても、魔法は元の武器に残るので、あふれない。
3. **キーの数を枠の数に合わせない。** キーは「唱える」と「次の魔法へ切り替える」の2つだけで、選んでいる魔法を唱える（2026-11-13、所有者）。空の枠は切り替えで飛ばす。枠が0の武器や、魔法が1つも入っていない武器では、唱えるキーは何もしない。キーは[操作](#操作)にある。
4. **どの魔法を選んでいたかは、武器が覚える。** 持ち替えて戻ると、前に選んでいた魔法のままである（案）。
5. **画面では、選んでいる魔法の枠を動かさない。** HUDは、選んでいる魔法を決まった位置の大きな枠に出し、武器の全ての魔法を、その上に小さく並べる。小さな列は枠の数で長さが変わるが、大きな枠の位置は動かない。並べ方は[UIのデザイン方針](art/ui-design.md#所持品の見せ方)にある。
6. **上限は画面の幅で決まり、6つとする（案）。** 操作は枠の数に左右されないので、上限はHUDの小さな列と持ち物の画面に並べられる数である。7つ以上の武器を作るときは、画面を作り直す。
7. **試合の途中で枠が減る場合に備える。** 今は、武器の枠の数は試合中に変わらない。強化や呪いなどで枠を変える物を足すときは、減ってあふれた魔法を後ろの枠から外してカバンへ入れ、入らなければ足元に落とす。

## 使用枠とカバン

2026-11-13に所有者が、使用枠とカバンを仕組みごと分けるとした。最初の案では、着けていない物を全てカバンに入れ、カバンの物を数字キーで使っていた。

- **使用枠**は、回復薬などの使う物だけを入れる。数字キーの1から順に、その番号の物をすぐ使う。枠は5つで、下のHUDに大きく並ぶ（案）。
- **カバン**は、それ以外の物と予備の使う物をしまう。カバンを手に入れると増えるのはカバンの方である。初めは6枠（案）。入る物は次のとおり。
  - 着けていない武器と防具。武器は、はめた魔法ごと入る
  - 武器にはめていない魔法
  - 使用枠に入りきらない回復薬などの使う物
  - 錆びた遺物、伝説の武器のパーツなど、[企画メモ](game-concept.md#伝説級アイテムの入手方法)の物
- 手に入れた使う物は、空いた使用枠へ先に入り、入らなければカバンへ入る。ほかの物はカバンへ入る（案）。
- カバンの物は持ち物の画面で使う。武器と防具は着けている物と入れ替わり、魔法はメイン武器の空いた枠へ入り、使う物は空いた使用枠へ移る（案）。
- ゲームパッドは数字キーがないので、選んでいる使用枠の物を使うボタンと切り替えるボタンで使い、空の枠は切り替えで飛ばし、選んでいた物を使い切ったら次の物を選ぶ（案）。
- どちらも1つの物が1つの枠を使い、重ねない。

## 操作

所有者が、アイテムも含めてキーボードで操作しやすい配置にするとした（2026-11-13）。一度は右手のJ、K、L、;で使い、その真上のO、Pで切り替える形に決めたが、同じ日に、技と魔法をQとEに、魔法の切り替えをRに、アイテムを数字キーに替えた。調べるキーはEを魔法に譲り、Fへ移した（所有者が了承）。マウスとゲームパッドの割り当ては、まだ案である。

| キー | 操作 | 前の割り当て |
| --- | --- | --- |
| W、A、S、D | 移動 | 同じ |
| Space | 跳躍 | 同じ |
| J | 通常攻撃 | 同じ |
| Q | 固有の技 | K |
| E | 選んでいる魔法を唱える | 調べる |
| R | 次の魔法へ切り替える | なし |
| 1〜5 | その番号の使用枠の物を使う | 1と2は武器の持ち替え |
| F | 調べる、開ける、店に入る、店を閉じる | E |
| Tab | 持ち物の画面を開く、閉じる | なし |

- 技、魔法、切り替えは左手で、WASDの指のすぐ上と横にある。
- アイテムは選んで使う形でなく、数字キーで直接使う。;とPは使わない。
- マウスは今と同じく、左のクリックで通常攻撃、右のクリックで固有の技とする（案）。
- ゲームパッドは、右の肩で固有の技、右の引き金で魔法を唱え、十字キーの上下で魔法を切り替え、左の引き金でアイテムを使い、十字キーの左右でアイテムを選ぶ（案）。ゲームパッドには数字キーがないので、選んで使う形を残す。跳躍、調べる、通常攻撃は今のボタンのままとする。

## 決めること

おすすめは整理した者の案である。所有者は、これらを実装して試しながら調整するとした（2026-11-13）。実装はおすすめで始める。

| 項目 | 実装で始める形 |
| --- | --- |
| MPの量、回復のしかた、HUDでの見せ方 | 最大値と今の値を持ち、時間で少しずつ戻る。HUDはハートの下に小さな青い玉で見せる |
| 固有の技の使う回数 | 待ち時間（クールダウン）。仮に3秒で、HUDの技の枠に覆いで見せる。MPを使うかは試して決める |
| 開いている間の画面の操作 | WASDは移動のまま。画面の選択は右手のI、J、K、L（上、左、下、右）か矢印キーとマウスで行い、UかEnterか右クリックで決める（買う、使う、着ける、外す）。左クリックは選ぶだけで、物は掴んで別の枠へ運べる（2026-11-18、所有者）。開いている間は攻撃、技、魔法を使わない |
| 店から離れたとき | 店の届く所を出ると、店の画面を閉じる |

以下は、ほかの決めることと、おすすめである。

| 項目 | 選択肢 | おすすめ | 理由 |
| --- | --- | --- | --- |
| 固有の技の数 | 1つの武器に1つ、武器ごとに0から2つ | 1つ | Kの1つで足り、今の特殊Actionの枠と同じ形で作れる |
| オフハンドが魔法の枠を足すか | 足す、足さない | 足さない | 魔法は武器の1本ごとに入る決まりと、2か所に分かれてしまう |
| オフハンドに片手の武器（二刀流） | 持てる、持てない | 当面は持てない | 両手で振る動きが要る |
| カバンの増え方 | A: 使うと枠が増え、減らない。B: カバンを装備として持ち替える | A。使用枠は数字キーで使うので増やさない | Bでは小さいカバンへ替えたときにあふれる |
| カバンがいっぱいのとき | 拾えない、捨てる物を選んで入れ替える | 入れ替える。捨てた物は地面に残り、誰でも拾える | 拾うたびに止まらない。捨てた物を他のプレイヤーが拾うと事件になる |
| 売るか | 店で売れる、売れない | 売れる（2026-11-18、所有者が売り買いをドラッグとショートカットでできるようにすると決めた）。どの店でも何でも買い取り、仮に買う値の半分（1以上）とする | 売る値は試合のコインの流れを見て調整する |
| 装飾品（指輪など）の枠 | 枠を作る、作らない | 当面は作らない | 想定にない。企画メモの伝説の指輪は、枠を作るか、カバンに入れているだけで効く物にするかを後で決める |
| 妨害で失う物 | カバンの物を落とすなど | 決めない | [Prototype方針](prototype-direction.md#育成と最終バトル2026-10-09)の妨害のペナルティと一緒に決める |

キーボードの配置は決まった。マウスとゲームパッドの割り当ては[操作](#操作)の案で、所有者はまだ決めていない。

## 今の実装との違い

2026-11-11の時点の実装は次のとおりで、この案に合わせるには作り替えが要る。

- 装備は1つの定義（`CharacterEquipmentDefinition`）が通常攻撃と特殊Actionの2枠（`CharacterLoadout`）を持つ。特殊Actionの枠は固有の技にそのまま使える。ただし今の特殊Actionは確認用で、剣は弓の矢、弓は近接である。
- 魔法の枠はない。武器は定義の並びの番号（`OwnedEquipmentCount`まで）で持っていて、1本ごとの持ち物がない。魔法を武器ごとに持たせるには、1本ごとの持ち物が要る。
- 剣の定義は、利き手の剣と反対の手の盾の部品を一緒に持つ。オフハンドを分けるには、盾を別の装備にする。
- 弓は反対の手に弓、背中に矢筒を付けるので、両手の武器の形にもう近い。
- 防具の定義（`CharacterSpriteSetDefinition`）は、持っている部位の絵で埋める部位が決まる（`Covers`）。騎士の全身も部位ごとに選べる。一体の防具は、埋める部位を全部まとめて着け外しする決まりが要る。
- 持ち物の仕組みはない。店の画面の袋は8枠で、着けていない武器と防具を見せるだけである。回復薬は買うとその場で飲む。
- 2026-11-13に、所持品、MP、魔法、決めたキーを森の確認用Sceneにつないだ（[ExecPlan](../exec-plans/completed/inventory-and-magic.md)）。持ち物の画面と店の画面も作り替え、開いている間も騎士が動ける。
- 入力（`InputSystem_Actions`）には、2026-11-13に[操作](#操作)のキーを足した。1と2の`Previous`、`Next`は探索Previewだけが使う。

## 絵の作業への影響

[装備と動きの要件](equipment-and-motion.md#増える作業)の作業の数え方に、次が加わる。

- 固有の技は、武器を1つ足すたびに1つ作ることになる。体の動きは武器種の今ある動き（振る、撃つ、走りながら振る）を使い、斬撃の形、飛ぶ物、動き方などの効果で違いを出せば、足すのは効果の絵だけで済む（案）。新しい体の動きを持つ技は、全ての胴と足に絵を足すことになる。
- 魔法は、唱える動きを武器種ごとに1組足せば、全ての魔法で使える（案）。
- 盾を外した反対の手が、今の絵でどう見えるかを確かめる。
- ローブなどの一体の防具は、胴と足を1組のシートで描く。
- カバンと枠に出すため、全ての物にアイコンが要る。固有の技と魔法も含む。
