# 装備と動きの要件

所有者が2026-11-07に整理した要件である。性能、価格、入手方法はこの文書の範囲外で、未確定である。

## 要件

- 武器種ごとに共通の動きを使う。同じ武器種の武器は同じ動きで、武器ごとに動きの絵を作らない。
- あらゆる防具と武器を組み合わせられる。組み合わせごとの絵は作らない。
- 装備を差し替えても動きを保つ。
- 防具は足、胴、頭の3部位に分け、部位ごとに着替えられる方向で進める。シリーズが違う部位を組み合わせても破綻しないようにする。決まりは[防具の部位デザイン規約](art/armor-part-design.md)にある。
- 速く走れる靴のように、足の枠へ性能を持たせる案がある。枠ごとの役割と性能、部位ごとに売るかは未確定である。
- 装備はidで引く。idを持つ装備は全装備の一覧へ自動で載り、個別の登録は要らない。
- 確認用に、一覧の全ての武器と防具を部位ごとに自由に切り替えられる。買わなくても、代金なしで身につけられる。

## 武器種と動き

| 武器種 | 動きの型 | 今の状態 |
| --- | --- | --- |
| 片手剣 | `Swing` | 向いた方向への半円の横切り。盾の側から剣の側へ、本人から見て左から右へ振る。走りながらは脚が走りを続け、止まって振ると前へ踏み込む |
| 弓 | `Shoot` | 動きの絵はまだない。走りと立ち姿のまま撃つ |

武器種は、武器の通常攻撃の動きの型で決まる。武器ごとに武器種を登録しない。確認用の画面も、この武器種で武器を分けて並べる。

動きは次の2つからできている。

- 上半身: 武器種ごとに持つ。武器の絵は手の位置へ付くので、上半身には描かない。
- 脚: 走りの脚は全ての武器種で共通である。止まって振るときの脚は武器種ごとに持つ。持たない武器種は立ち姿の脚のまま攻撃する。

所有者は2026-11-08に、攻撃だけでなく走りの上半身も武器種ごとに作ると決めた。武器を持つ腕の形が武器種で違うためである。片手剣の型は、剣の腕を下ろして拳を握った走りの胴を持つ。立ち姿は全ての武器種で共通の胴のままである。武器種の走りの胴を持たない胴の部位と武器種は、共通の走りを使う。

## 増える作業

| 足すもの | 作業 |
| --- | --- |
| 同じ武器種の武器 | 武器の絵だけ |
| 頭 | シート1枚 |
| 胴 | シート4枚と、武器種ごとに4枚（攻撃2枚、走り2枚） |
| 足 | シート4枚と、武器種ごとに2枚 |
| 武器種 | 全ての胴へ4枚、足へ2枚。基準の騎士には、武器を持った測定用の絵と、走りの素手の体も要る |

武器の組み合わせの数は作業に入らない。ただし、胴と足の数と武器種の数は掛け算になる。武器種を増やすときはこの点を判断する。

## 足、胴、頭の分割の検討

2026-11-07に、騎士と革装備の絵を切って組み合わせて確かめた。新しい生成は使っていない。

結論: 分割はできる。絵の枚数はほとんど増えない。所有者はこの結果を受けて、分ける形で作ると決めた。実装の記録は[防具の足、胴、頭への分割](../exec-plans/active/armor-parts-head-torso-legs.md)にある。

分かったことは次のとおり。

- 全身セットは同じ体の着替えなので、輪郭がずれない。切っただけでも、組み合わせた服として読める。
- 向きごとに1枚の頭を走りの全コマへ載せても崩れない。兜の位置は今の全コマが持っている。
- 境目の位置は決め直す必要がある。首の高さで切ると肩当てが頭の側へ入り、腰の高さで切ると前垂れの途中で色が変わった。頭はあごまで、胴は腰当ての裾まで、足は裾の下から靴までとする。
- 境目は切り口を合わせず、足、胴、頭の順に重ねて隠す。騎士と革装備の頭と胴を試作して走りの正面、横、背面で重ねると、どの組み合わせでも継ぎ目は崩れなかった。攻撃の上半身ではまだ確かめていない。

| 形 | 全身セット1着分のシート（武器種1つの場合） |
| --- | --- |
| 今の全身セット | 12枚 |
| 足、胴、頭に分けた場合 | 13枚（頭1枚、胴6枚、足6枚） |

分けても、同じシリーズの足、胴、頭を着れば今の全身セットと同じ見た目になる。全身セットを既定とする方針は保てる。

分けるときの制約は次のとおり。

- ローブや長いコートのように腰をまたぐ形は、足と胴に分けられない。全身専用の防具として別に扱う必要がある。
- ゲームは足、胴、頭の3層で表示する。今の部位は、頭が騎士、革、素顔、胴が騎士と革、足が騎士、布巻きサンダル、鉄の重靴である。
- 剣は胴の部位の拳そのものに付くので、手袋の色は胴に合う。弓のように拳を重ねる部品は今も騎士の拳の絵を重ねるので、手袋の色が違う胴で弓を持つときは別途対応する。
- シリーズが違う組み合わせは、立ち姿の48通りでは破綻しなかった。
