# Forest Map Preview Debug Scene

状態: **森マップを遊びながら調整するための確認用 / 本番Gameplay Sceneではない**

森マップを、本番の移動、攻撃、敵の判断で遊ぶためのPlaytest足場である。数値と試合の仮ルールだけをこの足場が持つ。

## 対象

- Scene: `Assets/ForestMapPreview/ForestMapPreviewDebug.unity`（Gitへ入れない、Build Settingsにも入れない）
- 足場: `Assets/Scripts/Playtest/Runtime/ForestMapPreviewDebug.cs`
- Builder: `Assets/Editor/Playtest/ForestMapPreviewDebugSceneBuilder.cs`
- 騎士の定義: `Assets/Data/Gameplay/Characters/HeroSprites.asset`

`Assets/ForestMapPreview/`は地図出力の置き場であり、Sceneを含めて全体を再生成できるのでGitへ入れない。作り方は[Asset導入・生成Workflow](../../development/asset-workflow.md)に従う。

## 責務

| 担当 | 役割 |
| --- | --- |
| `CharacterActor2D` | 移動、足元判定。本番と同じ |
| `HumanCharacterMoveInputAdapter` | `Player/Move`の入力。本番と同じ |
| `CharacterSpriteAnimator2D` | 向きと移動状態から表示Spriteを選ぶ本番Component。移動や判定には影響しない |
| `CharacterSpriteSetDefinition` | 防具の部位をまとめる定義Asset。頭だけ、頭と胴だけのように、持つ部位を選べる。5方向の絵、動きの型ごとのコマ、武器種ごとの走りの胴（`GetRun`）、コマごとの手と背中の位置、再生速度を持つ。手の位置には、利き手の拳の両端までの距離（`MainHandFront`、`MainHandBack`）もある |
| `CharacterGearDefinition` | 装備の部品1つ。付ける位置と5方向の絵だけを持ち、走りのコマは持たない |
| `CharacterEquipmentCatalog` | idを持つ全ての防具と武器の一覧。`Assets/Data/Gameplay/Equipment/EquipmentCatalog.asset`にあり、idから定義を引く |
| `CharacterEquipmentCatalogUpdater` | `Assets/Data/Gameplay/`の定義Assetが増減すると、一覧を集め直すEditorの処理。Scene Builderも実行する |
| `CharacterCombat2D` | 攻撃。本番と同じ |
| `CharacterChaseBrain` | 敵が追うか持ち場へ戻るかの判断。純C#の本番規則 |
| `CharacterChaseController2D` | Brainの結果をActorへ渡し、触れたときのダメージを与える本番Component |
| `ForestMapPreviewDebug` | 騎士、敵、宝箱の生成、追従Camera、足元の描画順、HUD、仮ルール。Playtest専用 |

`CharacterSpriteAnimator2D`はActorを読むだけなので、CPUやNetworkのCharacterにも同じComponentを付けられる。

## 表示の規則

- 8方向を、正面、斜め前、横、斜め後ろ、背面の5方向の絵で表す。左寄りの向きは右寄りの反転で表す。
- 斜めの2つのキーは同時には離れないため、`CharacterActor2D`は斜めから隣の向きへ変わっても向き（`Facing`）を0.08秒待って変える。その間に止まれば斜めの向きのまま立ち、止まったまま斜めへ振れる。表示も攻撃もこの向きを使う（2026-11-08までは表示だけが斜めを保ち、攻撃は隣の向きになっていた）。
- 走りは1周6コマで、1歩は着地、体重を乗せる、両足が浮くの3コマである。止まると向きに合う立ち姿へ戻る。斜めの走りは、画像生成がGIFとして描いた6コマで、騎士の見た目だけを正面・背面の絵から取り、動きは斜めの向きで描かれている。拍子は他の向きと同じで、1・4コマ目で脚がいちばん開き、3・6コマ目で両足が浮く。どの向きの走りも各コマの足元を地面の線へ揃え、浮くコマは3 pixel持ち上げる。正面と背面の2歩目の足は、1歩目の足の左右反転である。腕は剣と盾を持つので反転しない。立ち姿は走りのコマとは別に、足を揃えた絵を5方向分持つ。
- 動けない間と倒れた後は走りのコマを使わない。減速中は足の動きも同じ倍率で遅くなる。
- コマと立ち姿は幅96、高さ80の同じCellに揃えてあり、足元の位置が全コマで共通である。Pivotは`(0.5, 0.05)`。兜の幅を走りのコマに合わせたため、立ち姿は脚が伸びる分だけ走りより少し背が高い。

## 仮ルール

数値は`ForestMapPreviewDebug`の定数で、遊びながら調整する。

- 操作は移動WASD、通常攻撃J、特殊K、跳躍Space、装備切り替え1と2、宝箱を開けるE。
- 跳躍は高さ0.5、0.42秒で、`CharacterActor2D`の`Jump Height`と`Jump Seconds`で変える。空中では次の跳躍を受け付けない。
- 片手剣の通常攻撃は三段コンボで、Jを続けて押すと三段まで続く。攻撃中も足を止めずに動ける。今は三段とも、向いた方向へ半円に振る同じ横切りで、本人から見て左から右へ振る。
- 騎士の走る速さは6である。足の運びは毎秒17コマで、1秒に約5.7歩、1歩で約1.06マス進む。地面に着いた足が1コマに後ろへ動く量に合わせた値で、速さと同じ割合で変えると足が滑らない。
- 敵は6以内に近づくと追い、持ち場から14を超えた相手は諦める。速さは3で騎士の6より遅い。
- 敵のHPは40で、触れると1秒に一度10ダメージを与える。倒すとコインが1枚増え、30秒後に持ち場へ戻る。
- 開始時の装備は剣だけ。宝箱の中身はコイン10枚で、弓はショップで買う。
- 屋台の前でEを押すとショップが開く。回復薬は5コインでHPを30回復し、弓は20コインで買うとその場で持ち替える。
- 装備を替えると攻撃と一緒に手と背中の部品も替わる。
- HUDの「全装備を開く」で確認用の画面が開く。全装備の一覧にある武器と防具を、買わずに代金なしで部位ごとに選べる。上の段で武器、頭、胴、足を切り替え、武器は武器種でも絞る。中は名前とidの一覧で、枠は行数に合わせて伸び、多いときは高さを止めて送って選ぶ。身につけている物には印が付く。開いたまま移動と攻撃ができ、画面を押しても剣は振らない。ここで持った武器は買った数に入らず、1と2で買った武器へ戻る。
- 騎士のHPは100。倒れると1.5秒後に村へ戻って全回復し、2秒間は敵に触れてもダメージを受けない。育成中は脱落しない方針に合わせている。
- 村の噴水と祠の泉の前でEを押すと、既存の回復の泉のEventでHPが30回復する。それぞれ一度しか使えない。

地形は固定で、敵は候補20か所から12か所、宝箱は候補9か所から4か所を、Event配置と同じ`MapEventPlacementSelector`で試合ごとに選ぶ。候補は`ForestMapPreviewDebugSceneBuilder`の一覧で持つ。HUDにSeedを表示し、`ForestMapPreviewDebug`の`matchSeed`へ入れると同じ配置を再現できる。

## 装備の見た目

騎士は足、胴、頭の3層で表示し、武器は部品を重ねて表す。部位の決まりは[防具の部位デザイン規約](../../product-specs/art/armor-part-design.md)にある。

- 部品の位置は`MainHand`、`OffHand`、`Back`の3つである。剣は`MainHand`、盾と弓は`OffHand`、矢筒は`Back`に付く。
- 剣は1枚の絵をツールが「鍔から先」と「柄頭」に分け、それぞれ24方向へ回転させた部品で、角度は体のデータが持ち、走りの間は向きごとに固定する。握りは拳に隠れるので描かない。鍔から先は胴の絵が描く拳の刃の側の端に、柄頭は反対の端に付く。拳は着ている胴の部位の絵そのものなので、手袋の色は胴に合い、拳は腕と一緒に動く。絵を足しても走りと攻撃の全姿勢でそのまま動く。
- 重ね順は、足、柄頭、胴、頭、盾、鍔から先の順である。柄頭は腕に隠れる所が見えない。背を向けて走るときと立つときは鍔から先も胴の下へ回し、ツールが刃の向きへ3.5 pixel出して鍔を拳の下に見せる。背を向けて振るときは鍔から先を胴と頭の間に置き、拳や腕に隠れず兜には隠れる。
- 胴の部位は武器種ごとの走りの胴を持てる（`CharacterRunFrames`）。`ForestMapPreviewDebug`は装備した武器の武器種を`CharacterSpriteAnimator2D.SetWeaponKind`で渡し、走る間はその武器種の胴になる。持たない胴と武器種は共通の走りを使う。今は片手剣の型（`Swing`）だけで、剣の腕を下ろして拳を握った胴である。脚は全ての武器種で共通である。
- 体のSpriteRendererが足のコマを見せ、子の層が胴と頭を見せる。頭は向きごとに1枚の絵で、コマごとの兜の位置へ付く。斜め後ろの走りでは、描かれた頭が横を向いて首の上にないので、この位置を胴の首の付け根（襟の穴）から決める。敵のように足のコマを持たない体は、体のSpriteRendererが体全体の絵を見せる。
- 攻撃中は胴が動きの型の上半身に替わる。足は走りを続け、上半身と頭は走りのコマの兜の位置へ付くので、走りの揺れについていく。止まって振るときは動きの型の踏み込みの足を使う。上半身と頭は足のコマごとの兜の位置へ付くので、体が前へ乗り出す。硬直の前半は深く踏み込んだまま止まり、後半で戻り始める。
- 上半身は1振り4コマで、構え、振り2コマ、振り抜きの順である。振りの2コマは持続の前半と後半に対応する。剣はコマごとに測った手の位置と角度で腕と一緒に動き、盾の位置は攻撃の間動かない。
- 残像は動きの速い間だけ出す。背を向けた向きでは、剣と残像は体の向こう側を通る。
- `CharacterSpriteAnimator2D`が今のコマの手と背中の位置へ部品を毎Frame置く。左寄りの向きは体と一緒に反転する。
- 部品を体の前後どちらに描くかは、位置と向きから`CharacterSpriteAnimator2D`が決める。背中の物は背を向けたときだけ体の前に出る。
- 描く順は足、胴、頭、盾の手の部品、残像、利き手の部品、拳である。拳は剣や弓を握って見せる。回る武器の拳は胴の部位が持つ角度ごとの絵で、武器の柄の位置へ重ねる。弓など回らない部品の拳は、コマごとに切り出した絵である。
- `CharacterSpriteAnimator2D.Initialize`は全ての部位を1つの定義の絵にする。`SetArmour`は1部位だけを差し替える。手の位置、角度、拳は全ての部位で共通なので、武器の部品はそのまま残る。
- 体の描画順は`SetSortingOrder`で変える。部品の前後が崩れないよう、体と同時に更新する。
- 跳躍の状態は純C#の`CharacterJump`が持ち、`CharacterActor2D`が描く間隔で進める。高さは跳んでいる時間の割合に対する放物線である。足元の位置と当たり判定は動かさない。
- 跳んでいる間は、`CharacterSpriteAnimator2D`が子の層をまとめた`Lift`を高さの分だけ持ち上げる。体のSpriteRendererは足元の物体に付いていて動かせないので、隠して同じ足の絵を`Lift`の下の層で見せる。足元の影は高いほど小さくする。
- 足、胴、頭の3層の体は、足元にいつも小さな楕円の影を出す。走って各歩の着地のコマと、跳躍の着地では、足元に砂ぼこりを出す。砂ぼこりは体と一緒に動かないようSceneの直下に置き、体の後ろへ描いて少し上がりながら消える。体全体の絵を1枚で見せる敵には出さない。
- 影と砂ぼこりは、所有者の確認で走りが地面から浮いて見えたために足した。原因は、影がないこと、正面と背面の走りでは小さな片足しか地面に着かず足が縦に動かないこと、横の走りでは、地面に着いた足が1コマに15 pixel、1歩で0.47マスしか地面を送らないのに、体は1歩で0.92マス進み、足が滑ることだった。毎秒13コマの足の運びが表す速さは約3マス毎秒で、実際の6の半分である。横の走りでは、同じ大股のコマの間で上半身の高さが3 pixel違う。絵を描き直さずに効く影と砂ぼこりを先に入れ、残りは見え方を確かめてから判断する。
- 空中では足のコマを踏み切った時のまま止め、止まって振るときも踏み込まずに立ち姿の足で振る。専用の跳躍の絵は作っていない。

足し方と確認の仕組みは[Asset導入・生成Workflow](../../development/asset-workflow.md)に従う。

## Camera

- 縦14.0 Unity単位を使う。Sceneの値が優先されるので、`ForestMapPreviewDebug`の`cameraHeight`で変える。Play中の変更もすぐ反映される。
- 体の中心へ遅れなく追従する。追従の遅れと進行方向の先読みは違和感があったため入れない。
- Mapの外を映さないよう制限し、64 PPUの画素単位へ丸める。

## Map

- 地面、物、判定は`objects.json`と`collision.json`から作り、承認した検証用Sceneと同じ描画順を使う。
- 判定はMapCollision Layerへ置き、Map端にも壁を足す。
- 開始位置は村の広場`(60, 51)`。
